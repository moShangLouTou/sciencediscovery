# ScienceFlow 融合版试用指南

在 ScienceDiscovery（SD）会话中描述计算实验，由 Agent 使用 ScienceFlow（SF）执行，并把结果交付回会话。

## 1. 准备环境

使用 Linux / WSL，预先安装 Git、Node.js 22.19+、pnpm 11.1.2、uv 0.9+ 和 Python 3。

```bash
git clone --branch feat/scienceflow-run-reader --single-branch \
  https://github.com/moShangLouTou/sciencediscovery.git
cd sciencediscovery
scripts/setup-scienceflow-pilot.sh
```

准备脚本会下载配套代码、安装依赖、构建应用并创建试用会话。首次准备需要联网，默认数据目录为 `.tmp/scienceflow-pilot`，无需手动配置环境变量或准备初始候选。

## 2. 启动并配置模型

```bash
scripts/start-scienceflow-pilot.sh
```

打开 <http://127.0.0.1:4310>，使用启动成功后终端显示的登录 token 登录。在设置中配置网关和模型，再打开 `ScienceFlow research pilot` 或新建会话。SF 共享当前会话选择的模型。

如需自定义数据目录，给准备和启动脚本传入同一个目录即可。

## 3. 什么情况下会触发 ScienceFlow

| 用户请求 | 处理方式 |
| --- | --- |
| 明确要求运行计算实验或继续上一轮实验 | 进入 SF 流程，无需提及 ScienceFlow 名称 |
| 在计算任务中明确提及 ScienceFlow（大小写不限） | 进入 SF 流程，无需再补一句“运行”或重复确认 |
| 只说“分析、拟合、优化、研究”，执行意图不明确 | 先询问是否实际运行实验 |
| 普通问答、文献总结、方法解释或只讨论方案 | 不启动；“ScienceFlow 是什么”也不会触发实验 |
| 明确说“不要运行／只给方案”，即使提到 ScienceFlow | 不启动 |
| 查询状态、查看结果或重试交付 | 处理已有运行，不启动新实验 |

缺少可评测目标、指标或必要数据时，Agent 会先澄清。附件、引用中出现 ScienceFlow 不算执行请求。一次运行请求不会自动追加多轮实验。

触发判断由 Agent 根据这些规则完成；进入流程后仍需通过任务准备和权限检查。

## 4. 开始实验

### 使用已有任务

直接说明目标，并要求优先使用已有任务。例如：

> 请用 ScienceFlow 做一个数值优化实验：在二维平面上放 16 个点，让最远点距离与最近点距离之比尽可能小。优先使用平台已有任务及其评测器；先给出简短计划，再运行一次实验并报告实际指标。

Agent 会查找匹配任务、制定计划并启动实验，沿用该任务的评测规则。

### 准备新任务

说明目标、约束和评测指标，需要数据时直接在会话中上传。例如上传包含 `x,y` 两列的 `fit.csv` 后发送：

> 请用 ScienceFlow 拟合附件 fit.csv 中的数据，模型为 y = a*x + b，以 RMSE 最小为目标。a、b 必须有限且绝对值不超过 100，结果保存为 JSON {"a": 数值, "b": 数值}。请准备评测器、验证有效和无效样本，然后运行一次实验。

没有匹配的已有任务时，Agent 会准备并验证评测器，再制定计划和运行实验。自动生成的评测器属于探索性评测，请自行核对其科学合理性。

### 根据反馈继续

一轮结束后，在同一会话发送：

> 请读取上一轮的候选、实际指标和评测反馈，分析瓶颈并修改计划；以刚交付的有效候选继续运行一轮，比较两轮结果，变差也如实报告。

继续实验应保持相同目标和评测规则；需要修改它们时，应作为新实验提出。

## 5. 查看、停止和下载

右侧「工作区」中的「ScienceFlow」分组显示运行状态、最新指标和交付情况，并提供停止、交付重试和继续研究入口。收起右栏不会中断实验或状态更新。

结果会进入 SD 原有产物列表，可以打开查看和下载。判断实验效果时，以实际评测结果和交付产物为准，不保证每轮都能提升。

“继续研究”按钮会先填写输入框，检查并发送后才进入下一轮流程。

## 6. 适用范围

- 适合目标、约束和评测指标明确的 CPU 计算实验；实验室操作、GPU 训练等不在本次试用范围内。
- 当前 SF 生成的代码直接在本机执行，尚未纳入正式 Runner 沙箱，请在专用试用环境中运行。
- 当前试用面向 Linux / WSL 运行，其他平台及并发运行尚未验收。
